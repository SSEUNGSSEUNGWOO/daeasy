## 웹 접근 규칙 (절대 준수)
1. **네이버 계열(search.naver.com, blog.naver.com, rss.blog.naver.com) 크롤링 절대 금지.**
   robots.txt 전면 차단 + RAG 봇 명시 금지 대상이다. 시도조차 하지 말라.
2. 검색은 반드시 이 명령만 사용한다 (현재 작업 디렉토리는 pr-publish 루트다):
   ```
   uv run python scripts/search_kr.py "<검색어>" [--only korea] [--since YYYY-MM-DD] [--json]
   ```
   정책브리핑(korea)은 키 없이 되고, 네이버·카카오 검색 API는 키가 있어야 한다.
   **키가 없어 못 돌린 갈래는 "못 돌림"이지 "자료 없음"이 아니다** — research.md에 구분해 적어라.
3. 검색 결과의 상세 열람(WebFetch)은 허용 도메인만 가능하다: {{allowed_domains}}
   그 밖의 도메인은 열람하지 말고 검색 결과의 제목·요약·URL만 기록하라.
4. 구글 뉴스 RSS는 비상업 전용이라 쓰지 않는다.

## 추가 임무 — 데이지 관련 교육후기 후보 수집 (글의 '함께 보면 좋은 글' 카드 재료)
`https://daeasy.co.kr/cases` 를 WebFetch로 열어 게시된 교육후기 목록을 확인하고,
이번 건과 이어지는 글 2~3편을 고른다. 우선순위: ① 같은 과정의 다른 회차 ② 같은 기관·부문
③ 비슷한 주제. **실제 목록에 존재하는 URL만** `## 데이지 관련 교육후기 후보` 절에
`- 제목(추정 가능하면) / https://daeasy.co.kr/cases/<slug>` 로 기록한다.
목록을 못 열었거나 어울리는 글이 없으면 그 사실을 그대로 적는다 — URL을 지어내지 않는다.

## 작성 규칙
- `research.md` 형식:
  - `# 조사 결과 — {{slug}}` 제목
  - `## 검색 수행 기록`: 어떤 검색어로 어느 갈래(korea/naver/kakao)를 돌렸고, 못 돌린 갈래는 왜인지
  - `## 찾은 자료`: 자료별로 `- 제목 / 출처 기관 / 날짜 / URL / 핵심 내용 요약(2~3줄) / 확신도(높음·중간·낮음)`
  - `## 데이지 관련 교육후기 후보`: 위 추가 임무의 결과 (없으면 "후보 없음"과 사유)
  - `## 자료 없음`: 해당하면 "이 교육을 다룬 외부 기사·보도자료를 찾지 못함"을 명시
- **자료가 없으면 없는 대로 기록하고 끝낸다. 절대 지어내지 않는다.**
- 저작권이 명시적으로 확인된 사진(공공누리 등)만 `{{out_dir}}\images\외부\` 에 내려받고,
  출처 표기 문구(예: `(사진 = 화성시)`)와 이용 조건을 research.md에 적는다. 확인 안 되면 받지 않는다.
- brief.md의 수치와 다른 수치를 발견하면 "차이 있음"으로 표시만 하고 판단하지 않는다.

작업이 끝나면 research.md 저장 여부와 찾은 자료 건수를 한 줄로 보고하라.
