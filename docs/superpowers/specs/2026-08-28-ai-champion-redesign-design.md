# AI 챔피언 페이지 리디자인 — 섹션별 연출 + 골격 차별화

- 날짜: 2026-08-28
- 배경: `/ai-champion` 이 "AI가 만든 페이지" 인상을 줌 — 6개 섹션이 동일 골격(eyebrow → 헤드라인 → 카드 그리드), rounded-2xl 카드 15장+, `01 02 03` 모노 넘버링 3회 반복, 대구법 헤드라인 연속, 시각 자료 전무.
- 목표: 콘텐츠(제도 설명·숫자)는 유지하면서 섹션 골격을 서로 다르게 깨고, 홈과 동일한 GSAP 스택으로 스크롤·호버 반응형 연출을 넣는다.
- 결정: 접근 A (섹션별 연출 + 골격 차별화). 실물 이미지는 나중에 — 교체 가능한 자리만 설계.

## 공통

- `page.tsx` 는 서버 컴포넌트 유지 (metadata). 연출 섹션만 `components/ai-champion/*.tsx` 클라이언트 컴포넌트로 분리.
- `components/home/scenes/gsap-setup.ts` → `components/gsap-setup.ts` 로 승격, 홈 7개 씬 import 경로 수정 (내용 변경 없음).
- 모든 연출은 `matchMedia("(prefers-reduced-motion: no-preference)")` 안에서만 실행 — reduced 환경은 정적 레이아웃. 스크럽 제외 트리거는 `once: true`.
- 사이트 아이덴티티(Pretendard, ink/ink-warm/accent 토큰, 다크·화이트 교차)는 유지. 새 폰트·새 브랜드 컬러 도입하지 않음.

## 섹션별

1. **히어로** (다크, 유지) — 타이틀 라인·서브카피·등급 pill 을 GSAP 스태거로 순차 등장. `anim-page-fade-up` 제거.
2. **등급 Green/Blue/Black** — 균등 3분할 카드 → 확장형 비대칭 패널. 데스크톱: 가로 flex, 활성 패널이 넓어짐(기본 Blue). 모바일: 세로 아코디언. 헤더는 `<button aria-expanded>` 로 키보드 조작. Black 은 다크 패널로 차별화.
3. **학습 여정 6단계** — 카드 그리드 → 수직 타임라인. 좌측 sticky 헤딩 + 41시간 안내, 우측 타임라인. 스크롤 스크럽으로 진행선이 채워지고 단계 도트 활성화. 상단에 추후 사진으로 교체할 수 있는 비주얼 슬롯 구조(지금은 노출하지 않거나 가벼운 도식) — 회색 placeholder 를 공개 페이지에 노출하지 않는다.
4. **역량 평가** — `01 02 03` 넘버 카드 → 좌측 강조선 리스트(넘버링 제거). "수행평가 90 + 이러닝 10" 은 스크롤 진입 시 채워지는 비율 바 + 75점 컷 마커.
5. **인증 경로** — 카드 3장 → 구분선 리스트. 카드·넘버링 없음.
6. **운영 실적** — 구성 유지. 숫자(2,227 / 12 / 1,450)는 스크롤 진입 시 카운트업. 홈 `scene-ai-champion.tsx` 와 수치 동기화 주석 유지.
7. **CTA** — 유지.

## 카피

- 대구법 헤드라인 완화: "학습하고, 만들고, 역량을 증명합니다" 등.
- 6연속 uppercase eyebrow 반복을 줄인다 (전부 제거하지는 않음 — 톤 유지).
- 사실관계(숫자·제도 설명·인증 기준)는 변경하지 않는다.
