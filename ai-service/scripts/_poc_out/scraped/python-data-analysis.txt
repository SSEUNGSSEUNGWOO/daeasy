파이썬을 활용한 데이터 분석 3일 마스터

Python에 대한 기본적인 이해를 가진 중급자들을 대상을 설계된 과정입니다.
데이터 분석에서 필수저인 Numpy와 Pandas 라이브러리를 활용하여 데이터 전처리, 탐색적 데이터 분석(EDA), 그리고 시각화를 심화적으로 다룹니다.
또한, 기초 통계 개념과 머신러닝 기초 모델링을 통해 데이터를 효과적으로 분석하고 활용하는 방법을 학습하며, 실제 데이터를 활용한 프로젝트 기반 학습을 통해 분석 역량을 강화합니다.



학습 목표
Python의 Numpy와 Pandas를 활용한 데이터 전처리 및 탐색적 데이터 분석을 심화 학습
Matplotlib와 Seaborn을 사용하여 데이터를 시각적으로 표현하고 효과적으로 전달하는 방법 학습
기초 통계 개념을 활용해 데이터를 해석하고, 분석 결과를 기반으로 인사이트 도출
머신러닝의 기본 개념을 이해하고, 간단한 모델링 및 결과 해석 방법 경험
프로젝트 기반 학습을 통해 실무 데이터를 다루는 경험과 분석 역량 개발
학습 대상
Python 기초 문법과 데이터 처리 경험이 있으며, 데이터 분석 역량을 심화하고자 하는 사람
Numpy와 Pandas에 대한 기초 지식은 있지만, 실무에서의 활용도를 높이고자 하는 직장인과 연구원
데이터 시각화, 통계 분석, 그리고 기초적인 머신러닝 모델링을 통해 실무형 데이터 분석을 경험하고 싶은 사람
