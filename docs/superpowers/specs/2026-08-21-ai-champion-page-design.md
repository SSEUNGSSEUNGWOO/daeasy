# AI 챔피언 소개 페이지 마무리 설계

- 작성일: 2026-08-21
- 범위: `frontend/src/app/(site)/ai-champion/page.tsx` (283줄) 와 그 폴더에 추가할 OG 이미지
- 제외: 홈 `scene-ai-champion.tsx`, 다른 페이지, 카피 전문 재작성

## 배경

`/ai-champion` 은 텍스트 골격이 완성돼 있다. 히어로 → 3등급 → 학습여정 → 역량평가 →
인증경로 → 운영실적 → CTA 순으로 내용이 다 채워져 있고 카피도 정돈돼 있다.

비어 있는 것은 **전달 방식**이다. 283줄이 전부 텍스트 카드이며 도식이 하나도 없다.
그 결과 두 곳에서 내용과 배치가 어긋난다.

1. **등급이 성장 경로인데 병렬로 배치돼 있다.** 섹션 제목이 "기획에서 구현으로,
   구현에서 조직의 확산으로" 인데(`page.tsx:112-113`) 레이아웃은 같은 높이 카드 3장
   (`lg:grid-cols-3`, `page.tsx:119`) 이다. Green·Blue·Black 이 3지선다처럼 읽힌다.
   기관 담당자가 알고 싶은 것은 "우리 부서는 Green 부터 시작해 Blue 까지 올린다" 인데
   그 그림이 안 그려진다.
2. **순서가 전부인 내용이 격자에 흩어져 있다.** 학습 여정 6단계가 3열 격자
   (`page.tsx:153`) 라 눈이 가로로 읽다가 줄바꿈한다. 03 다음이 04 라는 것이 번호로만 겨우 전달된다.

여기에 두 가지가 더 있다.

3. **홈 섹션이 이 페이지보다 정교하다.** `components/home/scenes/scene-ai-champion.tsx` 는
   실적을 유리 패널 하나로 묶고 핵심 지표를 크게 세우며 4단계 파이프라인에 연결선을 그린다.
   반면 이 페이지의 실적은 `bg-blue-50` 평평한 3칸 표(`page.tsx:240-253`)다.
   "자세히 보기" 를 눌러 들어온 페이지가 더 밋밋하다.
4. **공유 미리보기 이미지가 없다.** `layout.tsx` 에 `openGraph` 설정은 있으나 이미지가 없어
   이 링크를 카카오톡·슬랙에 붙이면 그림 없이 뜬다. B2G 에서 링크는 카톡으로 돈다.

## 목표

사진 자산이 없으므로 **없는 것을 지어내지 않고, 이미 있는 내용을 도식으로 바꾼다.**

### 성공 조건

- 등급 3개가 한눈에 성장 순서로 읽힌다.
- 학습 여정 6단계가 모든 화면 폭에서 순서를 유지한다.
- 실적 블록이 홈과 같은 시각 언어를 쓴다. **숫자는 한 자도 바뀌지 않는다.**
- `/ai-champion` 링크를 공유하면 OG 이미지가 뜬다.
- `npm run lint && npm run build` 통과.

## 채택하지 않은 것과 이유

- **교육 산출물 스크린샷 3장(`public/course-outputs/`) 삽입** — 처음에 이걸 "역량 평가"
  섹션에 붙이려 했다. 확인 결과 **이 산출물은 AI 챔피언 교육에서 나온 것이 아니다.**
  다른 교육 결과물을 이 페이지의 평가 영역 옆에 두면, 라벨을 어떻게 붙이든 인접만으로
  AI 챔피언 결과물처럼 읽힌다. 공공기관 결재권자가 보는 페이지에서 할 수 없다. 폐기.
- **일정·비용·모집 시기·신청 방법 추가** — AI 챔피언은 행정안전부 사업이다. 모집·신청이
  데이지 소관인지 확인되지 않았고, 임의로 쓰면 공공기관에 틀린 정보를 내보내게 된다.
  소관임이 확인되면 별도 작업으로 다룬다.
- **교육 현장 사진 촬영·삽입** — `public/` 에 해당 자산이 없다.

## 설계

### 1. 등급 — 성장 계단

`tracks` 배열(`page.tsx:10-41`)의 **데이터는 그대로 둔다.** `accent` / `badge` 값도 유지한다.
바뀌는 것은 렌더링뿐이다.

- lg 이상에서 카드 상단을 계단식으로 어긋나게 배치한다. Green 이 가장 아래, Black 이 가장 위.
- Black 카드는 다크 채움(`bg-ink-warm text-white`)으로 종착점임을 드러낸다.
  이미 `badge: "bg-zinc-950 text-white"` 라 톤이 이어진다.
- 카드 사이 진행 표시(`→`)는 **lg 에서만 그린다.** 접힌 폭에서는 숨긴다.
  `scene-ai-champion.tsx:113-115` 주석이 지적한 원칙과 같다 — 3열이 1열로 접히면
  가로 연결선이 없는 방향을 가리킨다.
- 모바일에서는 오프셋 없이 세로로 쌓고, 각 카드에 `01` / `02` / `03` 을 붙여 순서를 대신한다.
- 기존 `reveal-stagger` 클래스는 유지한다.

Black 아래의 보수교육 안내(`page.tsx:136-138`)는 그대로 둔다.

### 2. 학습 여정 — 세로 타임라인

`journey` 배열(`page.tsx:43-50`)의 데이터도 그대로다.

현재 `<ol className="... sm:grid-cols-2 lg:grid-cols-3">`(`page.tsx:153`) 6칸 격자를
좌측 레일 세로 타임라인으로 바꾼다.

- 섹션 레이아웃은 **같은 페이지 "역량 평가" 섹션이 이미 쓰는 2단 구조**
  (`lg:grid-cols-[0.9fr_1.1fr]`, `page.tsx:170`)를 재사용한다. 좌측에 킥커·제목·설명,
  우측에 타임라인. 새 패턴을 만들지 않는다.
- 타임라인은 모든 화면 폭에서 세로다. 접히지 않으므로 연결선이 항상 옳은 방향을 가리킨다.
- 노드는 위에서 아래로 갈수록 진해지고, 마지막 "인증" 노드만 채운다.
- 41시간 안내(`page.tsx:162-164`)는 좌측 요약 블록 안으로 옮긴다.

`<ol>` 시맨틱은 유지한다 — 순서 있는 목록이 맞다.

### 3. 실적 블록 — 홈과 같은 시각 언어

현재 `page.tsx:240-253` 의 `bg-blue-50` 3칸 `<dl>` 을 홈 패널 구조로 바꾼다.

- 핵심 지표 하나(**인증평가 운영 1,450명**)를 크게 세우고, 나머지 둘(교육 수료 2,227명,
  표준 콘텐츠 12종)은 목록으로 내린다.
- 2026년 예측(`page.tsx:256-258`)은 **확정 실적과 다른 그릇에 담는다.** 같은 목록에 섞으면
  담당자가 품의서에 옮길 숫자까지 추정치로 읽힌다. `scene-ai-champion.tsx:104-105` 주석과 같은 이유다.

**숫자와 기준은 한 자도 바꾸지 않는다.** `page.tsx:254-255` 에 이미 경고가 있다 —
"홈(scene-ai-champion.tsx)과 같은 숫자·같은 기준이다. 한쪽만 고치면 두 페이지가 어긋나
실적 자체가 의심받는다." 이 주석도 유지한다.

### 4. OG 이미지

`frontend/src/app/(site)/ai-champion/` 에 두 파일을 추가한다.

- `opengraph-image.png` — 1200×630
- `opengraph-image.alt.txt` — 대체 텍스트

Next.js 16 파일 규약이 `og:image` / `og:image:width` / `og:image:height` / `og:image:alt`
메타 태그를 자동 생성한다(`node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/01-metadata/opengraph-image.md`).

**코드 생성(`ImageResponse`) 방식은 쓰지 않는다.** 그 방식은 `.ttf` 폰트 파일을 요구하는데
이 저장소에는 `app/fonts/PretendardVariable.woff2` (가변 woff2) 만 있다. Satori 는 가변 woff2 를
읽지 못해 한글이 렌더되지 않는다. 정적 PNG 는 폰트 문제도 런타임 비용도 없다.

`twitter-image` 는 따로 두지 않는다. Twitter 카드는 `twitter:image` 가 없으면 `og:image` 로
폴백하고, 카카오톡은 `og:image` 를 쓴다.

PNG 제작 방법: 1200×630 HTML 을 사이트 실제 폰트·색으로 만들고 헤드리스 브라우저로 캡처한다.
이미지 내용은 히어로와 같은 다크 톤에, 로고 · "행정안전부 공공부문 AI 챔피언" ·
"역량진단부터 인증까지 운영합니다" · 인증 1,450명. 작게 축소돼도 읽히도록 요소를 넷 이하로 제한한다.

## 손대지 않는 것

- 카피 전문 (킥커·제목·본문 문구)
- 실적 숫자, 인증 기준(수행평가 90 + 이러닝 10, 75점 이상)
- `assessmentAreas` / `certificationRoutes` / `operationScopes` 섹션
- **히어로 섹션** — 논의 단계에서 "히어로·실적을 홈 수준으로" 로 잡았으나, 코드를 보니
  히어로(`page.tsx:86-105`)는 이미 홈과 같은 `bg-ink-warm` + 같은 radial gradient + 등급 배지를
  쓰고 있다. 홈과 벌어진 것은 실적 블록뿐이므로 히어로는 건드리지 않는다.
- CTA 섹션
- 홈 `components/home/scenes/scene-ai-champion.tsx`
- 다른 페이지

## 검증

이 저장소에는 테스트 스위트가 없다(`frontend/CLAUDE.md`).

1. `cd frontend && npm run lint && npm run build` — 통과해야 한다.
2. 로컬 육안 확인:
   - 등급 3개가 lg 에서 계단으로 보이고, 좁은 폭에서 오프셋·화살표가 사라지는지
   - 학습 여정이 모든 폭에서 세로 순서를 유지하는지
   - 실적 숫자가 홈과 정확히 같은지 (2,227명 / 12종 / 1,450명)
   - `prefers-reduced-motion` 에서 애니메이션이 꺼지는지
3. OG 확인: 빌드 후 `/ai-champion` 의 HTML 에 `og:image` 메타 태그가 생성됐는지.
4. `/ai-champion` 렌더링 모드가 이전과 같은지 (정적)

## 미해결 / 후속

- AI 챔피언 교육 현장 사진이 확보되면 히어로 또는 학습 여정에 넣을 수 있다.
- AI 챔피언 산출물(수행평가 결과물) 스크린샷이 확보되면 역량 평가 섹션에 근거로 붙인다.
  현재 `public/course-outputs/` 의 3개는 **다른 교육 것이라 쓸 수 없다.**
- 모집·신청이 데이지 소관으로 확인되면 일정·비용·신청 방법 섹션을 추가한다.
