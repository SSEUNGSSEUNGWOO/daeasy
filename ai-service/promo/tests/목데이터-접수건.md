# 목데이터 — 홍보자료 접수 건 1개 (테스트용, 임의 작성)

> 실제 양식(docx)의 정확한 라벨은 pr-publish 쪽 `prpub scan` 이 정의한다. 이 문서는
> `pipeline/stages/intake.py` 의 `compute_slug()`, README 의 검증 오류 문구("항목 비어 있음: 교육기관",
> "교육 일자 형식 오류"), `prompts/writer.md`·`researcher.md` 가 brief 에서 기대하는 내용으로 역산한 것이다.
> 파이프라인이 실제로 읽는 것은 ③ `scan --json` 과 ④ `brief.md` 뿐이라, 이 둘만 맞으면 테스트가 된다.

## ① 접수 폴더 구조 (pr-publish 접수함 기준)

```
접수함/
└── 2026-09-10_화성시_AI챔피언2기/
    ├── 접수양식.docx            # ② 의 값이 들어 있는 양식
    ├── 01.jpg                   # 교육 장면 (강의실 전경)
    ├── 02.jpg                   # 실습 장면 (노트북 화면, 얼굴 안 보임)
    ├── 03.jpg                   # 단체 사진 (수료 후)
    └── 수료자명단.xlsx          # 첨부 — 본문엔 안 쓰고 인원 확인용
```

slug 는 `날짜_기관_과정` 으로 계산된다 → `2026-09-10_화성시_AI챔피언2기`
(`dates` 앞 10자 + `org` + `course`, 공백·특수문자는 `-` 로 치환).

| 항목 | 값 | 비고 |

| 과정명 (course) | AI챔피언2기 | **필수** |

| 교육 장소 | 화성시청 대회의실 | |
| 참여 인원 | 32명 (5급 이하 실무자) | 숫자는 brief 그대로 쓰이므로 정확히 |
| 강사 | 케이브레인컴퍼니 데이터교육팀 (강사 2명) | |
| 교육 개요 | 행정안전부 AI 챔피언 프로그램 2기. 1일차 생성형 AI 기초와 공문서 작성 활용, 2일차 노코드 데이터 분석(엑셀·구글시트)과 부서별 업무 자동화 아이디어 발표 | 글의 뼈대. 3~5문장 |

`org`·`course`·`dates` 세 개만 직접 읽는다 (slug 계산). 나머지는 `brief.md` 를 통해 LLM 에 간다.

## ④ `prpub build` 가 만드는 `out/2026-09-10_화성시_AI챔피언2기/brief.md`

```markdown
# 화성시 AI챔피언2기 — 등록 내용

- 교육기관: 화성시
- 과정명: AI챔피언2기 (행정안전부 AI 챔피언 프로그램 2기)
- 교육 일자: 2026-09-10 ~ 2026-09-11 (2일)
- 교육 장소: 화성시청 대회의실
- 참여 인원: 32명 (5급 이하 실무자)
- 강사: 케이브레인컴퍼니 데이터교육팀 (강사 2명)

## 교육 개요
1일차는 생성형 AI 기초와 공문서 작성 활용. 프롬프트 작성 원칙을 익힌 뒤 실제 부서 공문을 재료로
초안 작성·검토를 실습했다. 2일차는 노코드 데이터 분석(엑셀·구글시트)으로 부서 데이터를 직접 다루고,
마지막에 부서별 업무 자동화 아이디어를 발표했다.

## 현장 반응·성과
- 2일차 발표에서 12개 부서가 자동화 아이디어 제출
- 민원 응대 문구 초안 작성 시간 평균 20분 → 5분 (참가자 자체 측정)
- 만족도 4.7 / 5

## 참가자 한마디
"공문 초안을 AI 로 먼저 잡고 다듬으니 퇴근이 빨라졌다" — 기획예산과 주무관

## 사진
- images/01.jpg — 강의실 전경
- images/02.jpg — 실습 장면 (노트북 화면)
- images/03.jpg — 수료 후 단체 사진

## 홍보 채널
사이트(교육후기), 네이버 블로그
```

## ⑤ 같이 두면 좋은 오류 건 (접수 제외 테스트)

`2026-09-10_화성시_오류건/접수양식.docx` — 교육기관 공란, 교육 일자 `9월 10일` 로 기입.
기대 결과: 보고서 "접수 제외 건" 에 `항목 비어 있음: 교육기관; 교육 일자 형식 오류` 로 남고 파이프라인은 진행하지 않는다.

## 이 목데이터로 기대하는 판정 (루브릭 12/14 통과선 기준)

- 항목3(재료 충분성)은 성과 수치 3개·인용 1개·사진 3장이면 감점 없이 통과할 수준
- 리서처는 `korea.kr`·`mois.go.kr` 에서 "AI 챔피언 2기" 보도자료를 찾을 것이고, 없으면 "후보 없음" 으로 적어야 정상
- 글에 등장하는 수치는 위 값과 정확히 같아야 judge 의 사실성 항목이 깎이지 않는다
