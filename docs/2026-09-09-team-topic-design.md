# 팀 프로젝트 조별 주제 제출 페이지 — 설계

작성: 2026-09-09

## 배경

- CDSA 바이브코딩 팀 프로젝트 공고(`team-project-notice-v2.html`, 주제 예시 10선 A~J)를 교육생에게 배포하면서, **조마다 주제 방향을 제출**하고 **다른 조가 뭘 골랐는지 보이게** 해서 중복을 줄이고 싶다.
- 승우님 조건: kbrain-ems 와 무관하게 **단독·임시**. 끝나면 지운다.

## 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 위치 | daeasy `/team-topic` (사이트 헤더·푸터 없음, noindex) | 별도 Vercel 프로젝트·Supabase 프로젝트를 파는 것보다 기존 배포 라인에 얹는 게 가장 짧다 |
| 저장 | `public.team_topics` 1개, `team_no` PK, 주제는 자유 입력(`title`·`one_liner`·`submitted_by`). RLS 켜고 정책 0개 | 2026-09-08 에 anon INSERT 를 전부 걷어냈다. 그 결정과 맞추려면 쓰기는 Route Handler(service_role) 경유 |
| API | `/api/team-topic` GET(전체) / POST(조 번호 기준 upsert) + `rateLimit()` | 조당 1행, 재제출 = 덮어쓰기. 잠금·비밀번호 없음 (임시용) |
| 화면 | 한 페이지: 헤더(핵심 질문) → 예시 10선(컴팩트) → 5단계·규칙 → 조별 현황 카드 → 제출 폼 + 반투명 하단 고정 버튼 | 예시는 참고일 뿐이라 선택 항목 없이 자유 입력. 현황이 폼 바로 위에 있어 다른 조를 보고 적는다. 15초 폴링 |
| 중복 | 자동 판정 없음. 현황 카드가 곧 중복 방지 장치 | 자유 입력이라 코드로 겹침을 잡을 수 없다. "되도록" 피하기 — 강제 아님 |
| 스타일 | Tailwind. 히어로는 사이트 일러스트 `public/illust/quiz-vibe.webp`(노트북·플로차트·로켓)를 오른쪽에 두고, 배경은 그 일러스트의 바탕색 `#fefaf2`(mix-blend-multiply 로 경계 없음). 팔레트는 일러스트에서 뽑음: 네이비 `#1f3a93`(제목·핵심 질문 띠·규칙 밴드·선택 타일) · 연보라빛 틴트 `#eef1fb`/`#f7f8fd`(타일·입력창) · 주황 `accent-warm` · 흰 바탕. 본문 텍스트는 slate 단색. 숫자·모노그램은 Plus Jakarta(`NUM_FONT`), 이모지 없음. 섹션 번호 01~04, 기존 `Reveal`/`RevealList` 로 스크롤 등장, 반투명 다크 하단 바, press 시 scale, reduced-motion 대응 | v2(흰 카드 나열)가 밋밋하다는 승우님 피드백 → v3 다크 히어로. v3 의 따뜻한 베이지·반투명 회색이 "애매한 회색" 이라는 피드백(2026-09-09) → v4 네이비·하늘색·흰색. v4 도 "구려" → 승우님 제안으로 v5 는 이미지(사이트 일러스트)를 넣고 색을 그 그림에서 가져옴. 새 전용 일러스트가 생기면 `src` 만 교체. 애플 스킬에서는 타이포·재질·절제만 가져옴 |
| 조 개수 | `TEAM_COUNT = 8` 상수 | 드롭다운·검증이 이 값 하나를 본다 |

## 하지 않는 것

로그인, 조별 비밀번호, 운영자 화면(현황 카드가 곧 운영자 화면), 엑셀 내보내기, 실시간 소켓, 예시 선택 드롭다운(v1 에 있었으나 제거), 2단계 화면 전환.

## 검증

- `npm run lint && npm run build`
- 로컬 dev + Playwright: 제출 → 현황 카드 반영, 같은 조 재제출 덮어쓰기, 하단 바가 폼 도달 시 숨김, 모바일 폭
- 정리: 행사 끝나면 `drop table public.team_topics;` + 페이지·API 폴더 삭제
