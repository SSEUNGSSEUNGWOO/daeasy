Transformer 기반 딥러닝 마스터 과정

  • 딥러닝 프레임워크와 Transformer 기반 기술에 대한 고급 지식을 학습하고, 이를 실제 프로젝트에 적용할 수 있도록 설계된 과정입니다.
  • Tensorflow 및 PyTorch의 기초부터 Hugging Face 라이브러리와 한국어 모델 KoGPT까지, 딥러닝에 대해 종합적으로 익히며,
  • 최신 NLP(Natural Language Processing) 기술을 심도있게 다룹니다.
  • 실습 중심으로 구성되어있는 강의로, 실제 데이터를 활용해 고급 자연어 처리 문제를 해결할 수 있습니다.

학습 목표

  • TensorFlow와 PyTorch의 설치, 활용법을 학습하고 신경망을 구현 역량 확보
  • Transformer 모델의 구조와 원리를 학습하고, BERT, GPT 등 주요 모델의 차이 이해
  • Hugging Face 라이브러리를 통해 텍스트 분류, 질의응답 등 다양한 딥러닝 모델 학습
  • 한국어 NLP 기술을 활용해 한국어 특화 자연어처리 문제 해결
  • 실제 데이터를 활용해 기획, 모델링, 결과 분석까지의 전 과정을 체험 / 실무 능력 강화
  • 고급 NLP 문제를 해결하며 데이터 기반 인사이트를 도출하는 역량 확보

학습 대상

  • Python과 딥러닝에 익숙한 고급 사용자: 딥러닝 및 데이터 분석 경험이 있는 개발자, 데이터 분석가
  • NLP 전문가로 성장하고자 하는 데이터 과학자: 자연어처리 기술을 심화 학습하려는 사람
  • 실무 프로젝트 경험을 원하는 학습자: 실무형 데이터를 통해 종합적인 프로젝트를 수행하고자 하는 대상
  • Hugging Face 및 Transformer 활용을 원하는 사람: 최신 NLP 기술을 활용해 실질적인 성과를 내고자 하는 사람
