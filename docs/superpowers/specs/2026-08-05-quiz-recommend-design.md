# /quiz 교육 추천 — 설계

작성일: 2026-08-05

## 결정

규칙 기반 4문항 퀴즈 (승인: A안). 서버·LLM 없이 클라이언트에서 32개 과정을
점수화해 상위 3개를 추천하고, 결과에서 문의 폼으로 과정이 선택된 채 연결한다.

## 문항 → 매핑

| # | 질문 | 선택지 → 신호 |
|---|---|---|
| 1 | 어떤 조직이신가요? | 금융 → `[금융 특화]` 가중 / 유통·리테일 → `[유통 특화]` 가중 / 공공·제조·기타 → `[표준 과정]` 가중 |
| 2 | 어떤 역할로 참여하시나요? | 의사결정·리딩 → 리더십 키워드 / 현업 실무(비개발) → 활용 키워드 / 데이터·개발 담당 → 기술 키워드 |
| 3 | AI·데이터, 지금 어디쯤인가요? | 이제 시작 → `beginner` / 기본기 있음 → `intermediate` / 심화 필요 → `advanced` |
| 4 | 가장 이루고 싶은 것은? | 공통 리터러시 / 자동화·생산성 / 분석·시각화·리포팅 / AI 서비스·모델 개발 → 각 키워드군 |

## 점수 규칙

과정의 `title`(트랙·키워드) + `summary`(키워드) + `level` 로 채점:

- 트랙 일치 +3, `[표준 과정]` 은 기본 +1 (특화 산업 응답자도 표준 과정이 후보에 남게)
- level 정확히 일치 +2, 한 단계 차이 +1
- 역할 키워드 일치 +2, 목표 키워드 일치 +3
- 상위 3개 추천. 슬러그 하드코딩 없이 키워드 매칭 — 어드민이 과정을 추가해도 동작

## 화면 흐름

인트로 → 문항 1개씩 (진행 표시 1/4, 이전으로 돌아가기 가능) → 결과 3장
(트랙 배지·제목·요약·수준) → 카드별 **"이 과정으로 문의하기"** → `/contact?course=<slug>`
(문의 폼의 과정 select 가 미리 선택됨) + "다시 하기".

전환은 CSS 만 사용 (기존 모션 토큰 톤). reduced-motion 존중. gsap 불필요.

## 파일

- `(site)/quiz/page.tsx` — 서버: `fetchCourses()` + `revalidate=60`, 직렬화 데이터 전달
- `(site)/quiz/quiz-flow.tsx` — 클라이언트: 문항·채점·결과
- `(site)/contact/page.tsx` + `contact-form.tsx` — `?course=` 읽어 select 기본값 (소규모 수정)
- `README.md` — 진행 상태의 `/quiz` 항목 갱신

## 범위 밖

응답 저장·통계, LLM, 문항 어드민 관리. 문항 문구는 승우님 피드백으로 언제든 교체 가능.

## 검증

lint + build + Playwright: 4문항 클릭 통과 → 결과 3장 렌더 → CTA href 에
`course=` 포함 → contact 에서 해당 과정 선택 확인. 채점 스팟체크: 금융+리더 조합에
`[금융 특화] 금융 AI 리더십` 이 1순위인지.
