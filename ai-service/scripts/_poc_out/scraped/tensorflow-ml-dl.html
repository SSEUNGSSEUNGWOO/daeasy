TensorFlow로 구현하는 머신러닝·딥러닝 데이터분석

  • 데이터 분석 관점에서 머신러닝/딥러닝 모델을 이해하고, TensorFlow(Keras)로 직접 구현·학습·평가까지 수행하는 실습 중심 과정입니다.
  • 베이스라인 머신러닝 모델을 구성한 뒤, 신경망(MLP)을 TensorFlow로 구현하고 성능 개선/해석/추론 파이프라인까지 완성합니다.

학습 목표

  • 머신러닝 분석 파이프라인(전처리→학습→평가→해석)을 구성하고, 대표 모델을 적용할 수 있다.
  • TensorFlow(Keras)로 신경망(MLP)을 직접 구현하고, 학습/평가/저장/추론까지 end-to-end로 수행할 수 있다.
  • 과적합 방지 및 성능 개선(정규화, Dropout, Callback, LR 스케줄 등)을 적용해 모델을 고도화할 수 있다.
  • 실험 결과를 지표/시각화/오류분석으로 정리해 의사결정에 활용 가능한 리포트 형태로 전달할 수 있다.

핵심 내용

  • 데이터 전처리/검증: train/valid/test, 데이터 누수 방지, 스케일링/인코딩, 평가 지표 설계
  • ML 베이스라인: 회귀/분류 모델 비교 및 오류 분석(Confusion Matrix 등)
  • TensorFlow(Keras) 구현: 모델 정의(Functional/Sequential), compile/fit, Callback, tf.data 파이프라인
  • 성능 개선: 정규화(L2), Dropout, EarlyStopping, ModelCheckpoint, LR 스케줄
  • 운영 관점: 모델 저장/로드(SavedModel), 추론(inference) 함수, 입력 데이터 스키마/검증
  • 교육 성과
  • [교육 결과] 베이스라인 ML + TensorFlow 딥러닝 모델(MLP) 구현 코드, 성능 비교표, 오류 분석 리포트(요약본)
  • [업무 활용] 재사용 가능한 템플릿: 전처리 체크리스트, 평가 지표 표준, 실험 로그(전/후 비교), 모델 저장/추론 예제

학습 대상

  • 딥러닝 모델을 “이해”에서 끝내지 않고 TensorFlow로 직접 구현해보고 싶은 실무자/입문자
  • 데이터 분석 결과를 모델 성능/일반화/오류분석까지 포함해 설명해야 하는 담당자
  • 코드 기반 모델링을 시작하거나, Keras 기반 딥러닝 워크플로우를 빠르게 익히고 싶은 학습자
  • 필요 역량
  • 파이썬 기초 문법(함수/조건/반복, 리스트/딕셔너리) 이해
  • pandas로 데이터 로딩/기본 전처리 경험이 있으면 학습 효과가 더 높음
