엑셀로 배우는 데이터 분석 기초 3일 마스터

  • 데이터 분석 업무의 초심자가 3일에 걸쳐 실습 방식으로 학습을 하는 과정으로, 3일간의 과정을 통해 데이터 분석 업무의 전반적인 지식을 습득합니다.
  • 데이터 분석에 대해 개념을 시작으로 데이터 분석 업무에 대한 전반적인 실습 과정을 통해,
  • 현업에서 활용할 수 있도록 학습하는 과정입니다.
  • 각 단계별 실습과 실무 사례를 통해 실전 적용성을 높이고, 분석 결과를 명확히 전달하는 커뮤니케이션 능력을 강화합니다.

학습 목표

  • 데이터 분석의 개념과 중요성 이해
  • 효율적인 데이터 수집 및 전처리 능력 배양
  • 탐색적 데이터 분석(EDA) 능력 강화
  • 데이터 시각화 및 대시보드 구축 기술 습득

학습 대상

  • 데이터 분석에 관심이 있지만 기본 지식이 없는 초보자
  • 데이터를 활용한 실질적인 문제 해결 능력을 기르고자 하는 학생 및 직장인
  • 데이터 분석, 전처리, 시각화 등 기본 개졈을 배우고 싶어하는 전환 직종 희망자
