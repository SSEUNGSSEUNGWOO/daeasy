AI 융합 데이터 분석·개발 활용

  • ChatGPT, NotebookLM, Google Colab 등을 활용해 데이터 분석 개발 생산성을 높이고,
  • 전처리·EDA·시각화·리포트 작성까지 “재사용 가능한 분석 템플릿(Colab Notebook)”으로 완성하는 실습 중심 과정입니다.
  • 1일 동안 분석 업무 흐름을 표준화하고, AI를 활용한 코드 생성/검증/디버깅 패턴을 익혀 실무 적용 가능한 산출물을 확보합니다.

학습 목표

  • AI를 활용한 데이터 분석 개발 표준 워크플로우(계획→코드→검증→해석→리포트)를 구성할 수 있다.
  • Python(pandas) 기반 데이터 품질 점검·전처리 파이프라인을 자동화하고 검증 루틴을 적용할 수 있다.
  • EDA/시각화 결과를 근거(수치 기반)로 정리하고, 의사결정용 리포트 형태로 문장화할 수 있다.
  • NotebookLM을 활용해 문서/요구사항을 분석 계획·변수 정의·KPI 초안으로 변환할 수 있다.

학습 대상

  • 데이터 분석을 수행하지만 코드 작성/디버깅/리포트 작성에 시간이 많이 소요되는 실무자
  • Colab 기반으로 빠르게 분석 템플릿을 만들고 팀 단위로 재사용·확산하고 싶은 담당자
  • LLM을 분석 업무에 안전하게 적용(검증/가드레일)하고 싶은 조직/프로젝트 리더

교육 시간

  • 1일 - 8H
  • 교육 성과
  • [교육 결과] AI-융합 데이터분석 템플릿(Colab Notebook 1종) + 1페이지 결과 요약 리포트
  • [업무 활용] 재사용 프롬프트 패턴(계획/코드/검증/디버깅/리포트) + 데이터 품질 점검 체크리스트
09:00 ~ 10:00 · AI-융합 분석 개발 워크플로우 표준화
  • 목표: “AI를 쓰는 분석 개발 표준 절차”를 고정하고 재사용 구조를 만든다.
  • 프롬프트 패턴 5종: 계획→코드→검증→디버깅→리포트
  • 데이터/보안 가이드: 민감정보 제외, 샘플링/마스킹, 키 관리 개요
  • 산출물: 분석 Copilot Notebook 골격(섹션/함수 자리)
10:00 ~ 12:00 · 데이터 로드·품질 점검·전처리 자동화(검증 포함)
  • 목표: 분석의 핵심(데이터 정리)을 자동화하고 결과 신뢰성을 확보한다.
  • 스키마 요약: 타입/결측/분포/중복 자동 리포트 생성
  • 전처리 코드 생성: 결측/이상치/인코딩/스케일링(상황별)
  • 검증 루틴: assert/샘플링/요약통계로 AI 생성 코드 검증
  • 산출물: 데이터 품질 리포트 + 전처리 파이프라인(재사용 가능)
12:00 ~ 13:00 · 점심 시간 휴식
13:00 ~ 14:30 · EDA·시각화·인사이트 생성(근거 기반)
  • 목표: 차트 생성이 아니라 “근거 기반 인사이트”를 만든다.
  • EDA 체크리스트: 분포/상관/그룹 비교/세그먼트 분석
  • 시각화 템플릿(막대/히스토그램/산점도 등) 자동 생성
  • 환각 방지 규칙: “수치는 파이썬 계산 결과만” 리포트에 사용
  • 산출물: 핵심 차트 3종 + 인사이트 요약(근거 포함)
14:30 ~ 15:30 · NotebookLM: 문서/요구사항 → 분석 설계로 변환
  • 목표: 문서를 빠르게 읽고 “분석 계획/변수 정의/KPI”로 구조화한다.
  • 요구사항 정리: 분석 질문/지표/KPI 후보 도출
  • 변수 정의서(데이터 딕셔너리) 초안 생성
  • 산출물: 분석 계획 1장 + 변수 정의 초안
15:30 ~ 16:00 · [옵션] 로컬 LLM(Ollama) 데모(시간 여유 시)
  • 목표: 구축 교육이 아니라 “언제/왜 로컬을 쓰는가”를 이해한다.
  • 사용 시나리오: 보안/망분리/비용, 로컬 전환 체크리스트
  • 산출물: 로컬 전환 판단 기준(체크리스트)
16:00 ~ 18:00 · 미니 프로젝트: 분석 템플릿 완성 & 결과 요약(발표)
  • 목표: 1일 결과물을 “업무 재사용 가능한 패키지”로 고정한다.
  • 품질 리포트→전처리→EDA/차트→결과 요약 리포트 자동 생성
  • 재사용 가이드: 프롬프트/검증 체크리스트/운영 팁 정리
  • [발표] 2~3분 결과 공유 + 피드백
  • 산출물: 최종 Colab Notebook + 1페이지 요약 + 재사용 가이드

※ 세부 실습 데이터/도구는 조직 환경 및 정책에 따라 조정될 수 있습니다.
