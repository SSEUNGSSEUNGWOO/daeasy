노코딩 기반 데이터 분석과정

  • 데이터 분석에 대해 기초를 갖추고 있으며, 실무에 적용할 수 있는 심화 역량을 키우고자하는 중급자들을 위한 과정으로,
  • 데이터 분석의 전체적인 프로세스를 이해하고 데이터 수집부터 분석, 머신러닝까지 실습 중심으로 학습합니다.
  • 데이터 분석에 대해 어느정도 이해하나, 코딩에 자신없는 사람들을 위해 Orange3와 같은 노코딩 머신러닝 툴을 활용하여,
  • GUI기반으로 머신러닝 분석과정을 실습하고 분석 효율성을 높이는 방법을 배울 수 있습니다.

학습 목표

  • 데이터를 수집하고, 전처리 과정을 통해 분석 가능한 상태로 변환
  • 탐색적 데이터 분석(EDA)을 통해 데이터를 시각화하고, 유의미한 패턴과 인사이트를 도출
  • 노코딩 머신러닝 툴을 활용해 머신러닝 모델을 구성하고 평가
  • 분석 결과를 체계적으로 정리하여 실무에 적용 가능한 보고서를 작성

학습 대상

  • 데이터 분석에 대한 기초를 갖추고 있으며, 실무에 적용할 수 있는 심화 역량을 키우고자 하는 중급자
  • 머신러닝과 탐색적 데이터 분석 과정에 관심이 있는 직장인 및 데이터 분석 담당자
  • GUI 기반 도구를 통해 코딩 없이 분석 과정을 체험하고자 하는 학습자
