# AI 체험관 (체험형 스테이션) — 설계

작성일: 2026-08-28

## 결정

기존 `/quiz`(4문항 규칙 기반 추천)를 **"AI 체험관" 허브**로 교체한다 (승인: 허브형 A안).
방문자가 진짜 AI를 실시간으로 겪는 참여형 스테이션으로 구성하고, 체험 결과가
교육과정 추천 → `/contact?course=` 문의로 이어지는 전환 동선을 만든다.

- 주제: **공공 AI 실무 감각** — "내 업무에 AI를 써도 되는가"를 몸으로 확인
- 용도: 사이트 방문자 유입·전환용 공개 체험 (교육 신청 기관 사전진단은 추후 확장)
- 1차 범위: **허브 + 스테이션 ① "내 업무 AI 리포트"** 완성.
  ⑦ 바이브 코딩 라이브 · ⑧ 레드팀 게임은 허브에 "오픈 예정" 카드로만 노출
- 스테이션 ① 엔진: **Claude API (Haiku 4.5)** 서버 호출 + 스트리밍.
  sLM 자체 호스팅·사내 데스크탑 GPU 서빙은 검토 후 기각 (가용성·품질·보안 비대칭).
  로컬 GPU는 추후 "클라우드 vs 로컬 sLM 비교" 스테이션의 라이브 데모로 재활용 후보

## 허브 (`/quiz`)

- 제목: "공공 AI 실무 감각, 직접 겪어보세요" 톤의 랜딩
- 스테이션 카드 3장: ① 내 업무 AI 리포트 (active) / ⑦ 바이브 코딩 라이브 (오픈 예정) /
  ⑧ 레드팀 게임 (오픈 예정)
- 카드는 배열 데이터로 렌더 — 스테이션 추가/제거가 데이터 수정만으로 가능해야 한다
- 기존 4문항 퀴즈 코드(`quiz-flow.tsx`)는 제거. `/contact?course=` 연동 패턴만 계승

## 스테이션 ① — 내 업무 AI 리포트 (`/quiz/report`)

3단계 화면 흐름 (브라우저 목업으로 승인됨):

1. **입력**: 업무 한 줄 텍스트 입력 + 자주 쓰는 업무 칩 버튼(민원 응대·보도자료·통계
   정산·계획서 등, 누르면 입력창에 채워짐). 안내 문구: "개인정보는 적지 마세요 ·
   입력 내용은 저장되지 않습니다". 500자 제한
2. **생성**: API 스트리밍 응답을 실시간 타이핑으로 표시 — 써지는 광경이 체험의 핵심
3. **결과**: 리포트 본문(자동화 가능 업무 3가지 + 예상 절감 시간 + 보안 주의 1가지)
   + 추천 교육과정 1~2개 카드(추천 이유 포함) → "이 과정으로 문의" =
   `/contact?course=<slug>` + "다시 해보기"

## API 설계

`POST /api/experience/report` (Next.js Route Handler)

- 요청: `{ work: string }` — trim 후 1~500자 검증, 위반 시 400
- 서버가 published 교육과정 목록(title·summary·level·slug)을 Supabase(anon,
  RLS published-only)에서 조회해 시스템 프롬프트에 주입 — tool use·MCP 불필요
- Claude **Haiku 4.5** 스트리밍 호출, 응답 텍스트를 그대로 클라이언트에 스트림
- 출력 형식: 마크다운 리포트 + 마지막에 fenced JSON 블록
  `{"courses":[{"slug","reason"}]}`. 클라이언트가 JSON 블록을 분리해 추천 카드로
  렌더하고 본문에서는 숨긴다. 파싱 실패 시 `/courses` 전체 목록 링크로 폴백
- 시스템 프롬프트: 공공 업무 AI 활용 리포트 이외의 요청(잡담·주제 이탈·프롬프트
  변조 시도)은 정중히 거절하고 업무 설명을 요청하도록 고정
- Rate limit: 기존 `lib/rate-limit.ts`(Upstash) 재사용, IP당 **시간당 5회**,
  기존 정책대로 fail-open. 초과 시 429 + 친절한 안내 문구
- 저장 없음: 입력·응답 모두 DB에 남기지 않는다 (1차)

### 환경변수

- `ANTHROPIC_API_KEY` — frontend(Vercel) 신규, Sensitive 체크
- ai-service 는 의도적으로 이 키를 비워두는 것(Max 구독 소비)과 무관 —
  frontend 와 ai-service 는 별도 환경이므로 충돌 없음

  주제 이탈 입력 시 거절 응답
