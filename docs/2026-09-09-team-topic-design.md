# 팀 프로젝트 조별 주제 제출 페이지 — 설계

작성: 2026-09-09

## 배경

- CDSA 바이브코딩 팀 프로젝트 공고(`team-project-notice-v2.html`, 주제 예시 10선 A~J)를 교육생에게 배포하면서, **조마다 주제 방향을 제출**하고 **다른 조가 뭘 골랐는지 보이게** 해서 중복을 줄이고 싶다.
- 승우님 조건: kbrain-ems 와 무관하게 **단독·임시**. 끝나면 지운다.

## 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 위치 | daeasy `/team-topic` (사이트 헤더·푸터 없음, noindex) | 별도 Vercel 프로젝트·Supabase 프로젝트를 파는 것보다 기존 배포 라인에 얹는 게 가장 짧다 |
| 저장 | `public.team_topics` 1개, `team_no` PK. RLS 켜고 정책 0개 | 2026-09-08 에 anon INSERT 를 전부 걷어냈다. 그 결정과 맞추려면 쓰기는 Route Handler(service_role) 경유 |
| API | `/api/team-topic` GET(전체) / POST(조 번호 기준 upsert) + `rateLimit()` | 조당 1행, 재제출 = 덮어쓰기. 잠금·비밀번호 없음 (임시용) |
| 화면 | 공고 5개 섹션 그대로 + 주제 카드마다 "N조 선택" 배지 + 제출 폼·현황 표 | 공고와 제출이 한 페이지. 15초 폴링으로 현황 갱신 |
| 중복 | 이미 다른 조가 고른 주제를 선택하면 경고 문구만, 제출은 허용 | "되도록" 같은 주제 피하기 — 강제 아님 |
| 스타일 | 공고 CSS 를 `.tp` 로 스코프한 CSS 파일 | 임시 페이지를 Tailwind 로 다시 그리는 건 과함. 사이트 전역엔 영향 없음 |
| 조 개수 | `TEAM_COUNT = 10` 상수 | 드롭다운·검증이 이 값 하나를 본다 |

## 하지 않는 것

로그인, 조별 비밀번호, 운영자 화면(현황 표가 곧 운영자 화면), 엑셀 내보내기, 실시간 소켓.

## 검증

- `npm run lint && npm run build`
- 로컬 dev + Playwright: 제출 → 현황 표·배지 반영, 같은 조 재제출 덮어쓰기, 중복 주제 경고, 모바일 폭
- 정리: 행사 끝나면 `drop table public.team_topics;` + 페이지·API 폴더 삭제
