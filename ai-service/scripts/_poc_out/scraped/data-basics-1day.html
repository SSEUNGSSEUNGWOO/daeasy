초보자를 위한 데이터분석 기초 원데이

  • 데이터 분석을 처음 시작하는 학습자들을 위한 강의로 엑셀의 기초적인 함수을 실습하는 과정입니다.
  • 엑셀을 통해 데이터 불러오기부터 데이터의 형식에 대한 이해, 전처리 하는 방법을 배우고, 전처리된 데이터를 표준화 하는 방법을 배웁니다.
  • 정리가 되지 않은 데이터를 전처리를 통해 정리를 하면서 데이터 분석에 대한 전반적인 이해를 높이고,
  • 의미 있는 데이터를 도출 할 수 있으며, 보고서에 필요한 시각화 방법을 학습합니다.

학습 목표

  • 데이터 분석의 개념을 이해하고, 데이터 분석 사례를 이해
  • 데이터의 구조와 엑셀의 기능을 학습하고, 데이터 전처리를 이해
  • 데이터 분석 업무를 이해하고 실습

학습 대상

  • 데이터 분석/엑셀 환경에 익숙치 않으나, 데이터 분석에 입문해보고 싶은 학습자
  • 데이터 분석을 위한 프로세스를 이해하고자 하는 학습자
  • 정리 안된 데이터를 수작업으로 정라하고 있는 실무자자
