융합 데이터 분석 사례 교육

  • 공공·민간 공통의 “서비스 운영(리드타임/처리흐름)”과 “VOC(민원·문의·피드백 텍스트)”를 결합하여,
  • 병목 진단 → 원인(드라이버) 분석 → 개선 우선순위(액션 백로그)까지 완주하는 사례 기반 실습 과정입니다.
  • 교육은 범용 커리큘럼으로 운영되며, 실제 수행 시에는 교육 대상 조직의 업무 특성에 맞춰 사례와 KPI, 데이터셋을 변주하여 진행합니다.

학습 목표

  • 업무 문제를 분석 질문과 KPI로 구조화하고(목표→지표→진단지표), 의사결정과 연결된 분석 설계를 수행한다.
  • 서비스 운영 데이터(처리단계/시간/담당/채널 등)로 리드타임·SLA·병목을 진단하고, 개선 타깃을 도출한다.
  • VOC 텍스트(민원/문의/리뷰/CS 등)를 토픽·이슈 유형으로 구조화하고, 운영 지표와 결합하여 원인 드라이버를 찾는다.
  • 분석 결과를 “액션 백로그(임팩트×난이도×우선순위)”와 1페이지 요약 리포트로 패키징한다.

학습 대상

  • 서비스 운영(처리/업무흐름/품질/민원·CS) 데이터를 기반으로 개선 과제를 발굴해야 하는 담당자
  • 정량 지표뿐 아니라 VOC를 결합해 “왜 문제가 생기는지”까지 설명 가능한 분석 역량이 필요한 실무자
  • 공개 데이터 또는 비식별/가명처리 데이터로 사례 기반 교육을 운영하려는 기관·기업
  • 교육 성과
  • [산출물 1] KPI 트리 + 분석 설계서(1p)
  • [산출물 2] 리드타임/병목 분석 결과(차트팩) + VOC 토픽 맵(빈도·심각도·처리시간 결합)
  • [산출물 3] 개선 액션 백로그(우선순위) + Executive Summary 1p
